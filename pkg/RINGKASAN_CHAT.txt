RINGKASAN PROYEK (tempel di awal chat baru agar hemat token)
=============================================================
Tujuan: Stock Screener MODEL C (index.html + Flask + SQLite). Data tidak boleh ganda/tertimpa; kalkulasi dashboard tidak diubah.
Lokasi kerja: folder proyek Windows C:\\Users\\Administrator\\Documents\\Data\\Screener ; paket: screener_sqlite.zip (README.txt di dalamnya).

SUDAH SELESAI
1. Migrasi ke screener.db (skema v2): satu dataset per (jenis,tanggal); jenis px,days(5%),tipe,sat(1%),kl + global nm,klc,hc; origin; audit_log; backup otomatis.
   migrate.py (tertanam HTML -> arsip data/*.csv -> IndexedDB fill-only), validate.py (jumlah, isi, sidik jari kalkulasi), migrasi.bat.
2. parsers.py = port 1:1 parse() JS (uji paritas vs JS asli lulus). Perbaikan: file multi-tanggal dipisah per tanggal; data >=1% persen>100 ditolak;
   file klasifikasi berheader SHARE_CODE + kolom Local_/Foreign_ kini dikenali sebagai kl. Putar-balik 5%/1% (15/15 identik).
3. server.py: /api/upload /api/data(ETag,gzip) /api/hc /api/migrate/legacy /api/status /api/watchlist /api/live/update /api/fundamental/<kode>.
4. live.py: yfinance mengisi px (kode tanpa .JK) tanggal setelah px resmi terakhir; origin='yfinance'; tak pernah menimpa data resmi; digantikan saat Ringkasan IDX diunggah;
   kalibrasi harga/volume; auto tiap 5 menit jam bursa; data KSEI tidak disentuh. Kolom tak tersedia (foreign, bid/offer, freq)=0, nilai=estimasi.
5. UI index.html: sidebar = Watchlist > Top Gainer/Loser (mingguan 3) > widget live (titik/garis denyut, bar naik/turun, hitung mundur) > Input data.
   Animasi kedip hijau/merah saat harga berubah; auto-refresh klien (poll /api/status 30 dtk).
6. Tab Fundamental di panel detail emiten (fundamentals.py, cache 12 jam di tabel fundamentals_cache): 8 kartu, kuadran, skor gabungan 14,
   sinyal BUY/HOLD/SELL/WAIT + 4 cek, rincian skor, 8 uji kualitas, peringatan, garis 52 minggu tipis (3px), tombol detail. Aturan lengkap di README.txt.

7. Rapi (terbaru): Fundamental ringkas (pill valuasi + bar kuadran seperti referensi, sinyal hanya label, rincian skor di tombol Detail), satu font
   (Space Grotesk) & ukuran kecil seragam di tab Fundamental + header panel. Halaman depan: tabel akumulasi 25 baris (+25), kartu "Holder terbanyak"
   (>=5% + 1-5%, hanya pemegang aktif, 10 baris, urut per kolom, lebih banyak +10, ↻, otomatis ikut refresh).

8. Keputusan gabungan MODEL C (kartu di bawah header panel emiten): K = arus dana KSEI 35% + teknikal BSX 25% + dini 10% + fundamental 30%
   (bobot/ambang di objek FW index.html), keputusan BUY/HOLD/SELL/WAIT dgn gerbang (lihat README). Kartu holder DIHAPUS -> kolom "Holder" di tabel depan
   (>=5% + 1-5%, pemegang aktif saja, bisa diurutkan). Screenshot review: review_*.png.

9. Revisi terbaru: SATU keputusan gabungan (BUY/HOLD/SELL/WAIT + skor) dipakai di panel emiten & halaman BUY/SELL (tombol/skor BUY lama dihapus; tombol BUY di
   Fundamental dihapus, diganti box Posisi 52 minggu di kanan valuasi). Font tunggal JetBrains Mono, tombol persegi. Tabel depan: nama lengkap di bawah kode, label
   di bawah bar skor. Telegram (telegram.py/telegram_setup.py/telegram.json): notif OTE sisi beli dgn batas limit; chat_id diisi via py telegram_setup.py.
   Fundamental massal: cache /api/fundamental/cached + antrean prefetch. Fundamental tersimpan di tabel fundamentals_cache; close di px payload[0].

BELUM / CATATAN

- Folder data Anda hanya berisi 21 CSV (laporan menyebut 318): salin sisanya lalu migrate ulang. File klasifikasi 2026-10-30 perlu migrate ulang (perbaikan parser).
- Keputusan gabungan belum di tabel Akumulasi depan (fundamental baru ada utk emiten yg sudah di-cache); fase pasar belum ikut dihitung.
- Telegram belum diuji ke server Telegram asli (hanya HTTP palsu); chat_id belum diisi; token perlu di-revoke setelah uji karena tampil di chat.

- Error 'RR ... destructure C' pada komponen React lama ada juga di HTML asli (tidak diubah).
- Konvensi: jawaban singkat, tanpa teks panjang; tema gelap; jangan ubah rumus kalkulasi tanpa persetujuan.
